# Banana Tree (Touch Slider Game)

This project is my solution for the homework in VIMIA347

## Build

It can be built with Simplicity Studio 5 or you can access the pre-built binaries on the releases page.

## Controls

With the touch slider you can set the difficulty and move the platform.

To start the game press PB1.

After the game is over, you have to reset to restart.
